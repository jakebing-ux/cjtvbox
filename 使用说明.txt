CJTVBOX 本地包（影视仓3 / OK影视2.5 / 安卓4）
========================================
= 组成 =（以龙门影视 box.iqinu.com 为基础）
 1) 龙门源 82 个（jar 源走 lm60601/dx0301/dx260509，ext 已本地化）
    —— jar 源 41 个（龙门影视/天天秒播/星芽短剧/豆瓣/哔哩/斗鱼等）
    —— 采集源 41 个（量子/非凡/豆瓣/OK/黑木耳等资源站，在线接口）
 2) 采集源增量 38 个（按你的列表新增，去重 20 个龙门已有的）
    —— 红牛/火狐/光速/索尼系/KK/AG/乐播/魔都/神马/天翼/狐狸/云海/
       速更/闪电/量子备用/浮巧/宝盒网盘等
 3) 直播 4 组 + 解析接口 38 个 + flags 61

= 目录结构 =
 CJTVBOX/
 ├─ CJTVBOX.json   （配置：120 源）
 ├─ jar/           （lm60601/dx0301/dx260509/spider 4个jar）
 ├─ json/          （龙门源本地配置 11 个）
 └─ js/            （龙门源本地脚本 4 个）

= 用法 =
 1. 把 CJTVBOX 文件夹整体复制到盒子任意目录（保持结构）
 2. 播放器 → 设置 → 本地配置 → 选择 CJTVBOX.json
 3. 首页源建议选「龙门影视」或「接口┃量子资源」

= 在线配置地址 =
 直连代理 (推荐)：https://v4.gh-proxy.org/https://raw.githubusercontent.com/jakebing-ux/cjtvbox/main/CJTVBOX.json
 CDN：https://cdn.jsdelivr.net/gh/jakebing-ux/cjtvbox@v1/CJTVBOX.json
（jar 走 v4 代理分发；json/js 走 jsDelivr）

= 说明 =
 - 采集源为远程在线服务，失效后改 CJTVBOX.json 对应 api 即可
 - 不用的源可自行删除
